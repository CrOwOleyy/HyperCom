# Code of Conduct

## The short version

Be respectful. Disagree about code, not about people. Harassment,
discrimination, and personal attacks aren't welcome here, in issues, pull
requests, or any other project space.

## Scope

This applies to every space tied to the project: the issue tracker, pull
requests, and any discussion that happens under the project's name.

## Reporting

If someone's behavior in a project space is a problem, contact
[leyy@pepepak.fr](mailto:leyy@pepepak.fr). Reports are handled privately,
and reprisal against someone who reports in good faith is itself a
violation.

## Enforcement

Maintainers can remove comments, close issues or pull requests, or block a
contributor from the project, at their discretion, when this code of
conduct is violated.
